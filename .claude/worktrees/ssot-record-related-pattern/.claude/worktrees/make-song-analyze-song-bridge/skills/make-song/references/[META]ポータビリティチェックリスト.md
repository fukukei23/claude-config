# ポータビリティチェックリスト（META・AI変更時の差し替え手順）

> 音楽生成AIが変わった時、**Layer 1（基礎）はそのまま再利用**。**Layer 2 のみ本リストで再検証して書き直す**。

---

## 新AI導入時の検証チェックリスト

音楽生成AI（MiniMax→別AI）に乗り換える時、以下を1つずつ実測検証:

- [ ] duration/BPM 指定パラメータの有無（直接指定できるか）
- [ ] 構造タグ14種の認識（どれが効くか）
- [ ] 括弧 `(text)` 記法の解釈（backing/ad-lib として効くか）
- [ ] コロン `[Verse: ...]` 記法の解釈（効けば `[L1]` へ昇格候補）
- [ ] 歌詞最大文字数
- [ ] 圧縮率（設計値に対する到達率・60-70%か別の値か）
- [ ] 声質プロファイル固定の効き（同一文字列で声色ブレ防止できるか）
- [ ] 高音質パラメータ（sample_rate/bitrate 対応）
- [ ] 失敗パターンの再現性（`[L2]失敗パターンカタログ.md` の各項目が再現するか）
- [ ] ひらがな化の必要性（漢字を誤読するか）
- [ ] cover 相当機能の有無（曲調維持で歌詞修正できるか）

## 知見の移行ルール

| 状況 | アクション |
|---|---|
| 新AIで効いた Layer 1 技法 | そのまま（Layer 1 は AI 非依存なので不変） |
| 新AIで効かなかった Layer 1 技法 | 降格・注記（「MiniMaxでは効くが新AIでは効かない」） |
| 新AIで効いた新技法 | 4象限①（確定・汎用）候補へ昇格 → Layer 1 還元検討 |
| MiniMax固有で汎化できる知見 | Layer 1 還元（例: 圧縮率はAI固有だが「AIは設計値に届かない」は汎用教訓） |

## 4象限マトリクス（知見仕分けの基準）

|  | 検証度高（複数AI/理論裏打ち） | 検証度中（単AI実測） | 検証度低（推測） |
|---|---|---|---|
| **汎用**（AI非依存） | ① 確定・汎用 → **Layer 1** | — | ③ 仮説・汎用 → 検証待ち |
| **固有**（AI依存） | — | ② 実測・固有 → **Layer 2** | ④ 仮説・固有 → 検証待ち |

**昇格**: ③④は実測で効果確認 → ①②へ。①のうち特定AIで効かないものは②へ降格（循環）。

---

## 使い方

AI変更時に本リストを上から順に検証。結果に応じて `[L2]` ファイル群を書き直す。`[L1]` は原則触らない（AI非依存のため）。
