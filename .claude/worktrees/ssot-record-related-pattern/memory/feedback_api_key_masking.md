---
name: APIキーのマスク表示
description: ファイル読み込みやコード表示時にAPIキー・シークレットをマスクする
type: feedback
---

ファイル内容やコードをチャット上に表示する際、APIキー・パスワード・トークン等のシークレット値は必ずマスクして表示すること。

例: `GLM_API_KEY=539abc...` → `GLM_API_KEY=<マスク済み>`

**Why:** ClaudeCodeがスクリプトを読み込んだ際、APIキーがチャット上にそのまま露出した。ユーザーが明示的に指摘。

**How to apply:** Read/表示/引用するコード内にAPIキー・トークン・パスワードらしき値が含まれる場合、値部分を `<masked>` や `***` に置き換えてから出力する。ファイル編集の際は実際の値をそのまま書き込む（マスクするのは表示のみ）。
