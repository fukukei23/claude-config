# 音楽的キャラクター辞書（Layer 1・AI非依存・確定）
> Phase 0.5 で使う「ジャンル→系統→エッセンス→ジャンル具体語」の翻訳辞書。
> 素材（個別のコード進行・スケール定義）は [L1]楽曲制作基礎_ジャンル別.md を参照。本ファイルは素材を束ねて3層ドリルダウン可能にする。

## 核心制約（厳守）
AI音楽生成（Suno/Udio/MiniMax）は直接コード進行指定を無視・誤唱する。
→ **コード進行の文字列（Am→F→G→C 等）はプロンプトに書かない**。
→ 定番進行が持つ感情・ジャンル語を「具体語」として GMIV（Phase 1）に渡す。
→ **アーティスト名（コブクロ/EXILE 等）も直接プロンプトに書かない**。系統名は人間用ラベル・下記マッピングで具体語に翻訳して渡す。

## 構造: 3層ドリルダウン

```
第1層: ジャンル（10種・[L1]楽曲制作基礎_ジャンル別.md と整合）
└─ 第2層: 系統（各ジャンル3-6種・アーティスト/楽曲イメージで命名 → 具体語マッピング）
   └─ 第3層: エッセンス追加（オプション・複数可・共通修飾語プール）
```

### 第1層: ジャンル
J-POP / K-POP / 洋楽POP / HIPHOP / R&B / ロック / EDM / アニソン / Lo-Fi Hip Hop / 和風・サイバー和
（各ジャンルの詳細構造・サウンド・ボーカル作法は [L1]楽曲制作基礎_ジャンル別.md を参照）

### 第3層: エッセンス（共通修飾語プール・複数追加可・3-4個目安）

| エッセンス | 追加する具体語 |
|---|---|
| **+HIPHOP** | add trap hi-hats, 808 beat, rap verse, rhythmic flow |
| **+クラシック** | add orchestral strings, piano arpeggios, cinematic |
| **+エレクトロ** | add synth pads, EDM build-up, electronic drops |
| **+和** | add shamisen/koto, Japanese pentatonic, traditional flavor |
| **+ジャズ** | add jazz chords, swing rhythm, smoky |

### 個別選択ルート（B・上級）
和声/メロディ/リズム/ダイナミクス/転調を要素ごとに指定。感情→定番コード進行の対応は [L1]楽曲制作基礎_ジャンル別.md §A を参照。

### リファレンス曲逆引き（Cルート）
持ち込み曲（reverse-engineer-song 仕様書 / Reference 3曲）があれば、その曲のジャンル・系統を第1-2層に当てはめ。主軸1つを選び、副要素をエッセンス/個別選択で補う。

## Phase 0.5 での使い方
1. ユーザーにルート選択を提示: A.ジャンル起点ドリルダウン（デフォルト）/ B.個別選択 / C.リファレンス曲
2. Aの場合: 第1層ジャンル → 第2層系統 →（Full時）第3層エッセンス を順に選択
3. 選んだ系統の「ジャンル具体語」+ 追加したエッセンスの具体語 を結合し、Phase 1 GMIV（Genre/Mood）に反映
4. コード進行文字列・アーティスト名は絶対にプロンプトに書かない（人間の設計理解用のみ）
5. Quick Mode は第1-2層のみ・Full Mode は第1-3層（エッセンス追加可）
