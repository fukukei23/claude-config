# 発音ルール（硬制約・曹仁v1-v8の教訓集約）

> MiniMax music-2.6 向けの発音制御ルール。**これらはスキルの硬制約**。違反すると造語/誤読/誤発音が量産される（曹仁v1-v7の失敗事例より）。

## ★助詞「は」→「わ」（必須・最優先）

MiniMax music-2.6 は助詞「は」を **「ha」** と誤発音する。歌詞では全て「わ」と書く:

- 「樊城は倒れぬ」→「はんじょう**わ** たおれぬ」
- 「曹仁は敗れぬ」→「そうじん**わ** やぶれぬ」
- 「心は硬いぞ」→「こころ**わ** かたいぞ」

※ 名詞の一部の「は」（花=はな/始まり=はじまり）は変えない。**助詞の「は」だけ「わ」**。

## ボーカル切替タグ

- **(F)** = female ボーカル
- **(M)** = male ボーカル
- 男女デュオ時は歌詞中の該当箇所に括弧で明示

## 表記ルール

- **漢字は使わない**: ひらがな表記で誤読回避（AIは漢字を読めない）
- **長音「ー」**: 母音延長として扱う
- **「ん」**: 母音 n として韻に使える

## ❌ 絶対禁止

1. **造語を作らない**（曹仁v1-v4「まいふせつ」/ v1-v5「まいれぬ」「すがわだ」級の意味不明語）
2. **存在しない活用形**（曹仁v6「きたったのだ」→正: 「きた」）
3. **慣用句の誤用**（曹仁v6「ねをひかれ」→意味確認不足）
4. **漢字をそのまま書かない**（AIが誤読）

## ✅ 生成前チェックリスト（Phase 2完了前に必ず実行）

- [ ] 全「は」助詞を「わ」にしたか
- [ ] 造語・不自然な日本語はないか（1行ずつ音読）
- [ ] janomeで読みを確認したか（一般語・`scripts/kanji_to_hiragana.py`使用）
- [ ] 固有名詞の読みは史実/辞書と一致してるか（`固有名詞マップ.md`参照）
- [ ] 漢字版を併記したか（ユーザー確認用）
- [ ] 韻の母音列は揃ってるか（`韻技術.md`参照）
