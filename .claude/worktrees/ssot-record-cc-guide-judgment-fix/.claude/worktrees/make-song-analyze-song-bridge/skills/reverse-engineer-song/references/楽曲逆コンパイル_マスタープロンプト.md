# 楽曲逆コンパイル — 生成AI用プロンプト・マスタープロンプト

## 概要

YouTube動画（楽曲）をリバースエンジニアリングし、音楽/画像/動画の3モダリティの生成AI用プロンプト仕様書を出力するための**汎用マスタープロンプト**。任意の楽曲に適用可能。`reverse-engineer-song` スキルが使用する。

> **二重管理注記**: 本ファイルが一次ソース。skill側（`~/.claude/skills/reverse-engineer-song/references/楽曲逆コンパイル_マスタープロンプト.md`）に実体コピーが存在する。マスタープロンプト更新時は**両方**を修正すること。

## マスタープロンプト（以下をGemini等に投げる）

# 役割定義
あなたはプロの音楽プロデューサーであり、同時に映画やハイクオリティMVを手がける映像監督、および生成AI（Suno, Udio, Midjourney, Stable Diffusion, Runway, Luma）の特性を限界まで知り尽くしたプロンプトエンジニアです。提示された1つのYouTube動画（楽曲）を五感と技術的ロジックで徹底的にリバースエンジニアリング（逆コンパイル）し、その「世界観」「音像」「映像構造」を完全に別の生成AIで再現・制御するための【完全再現・生成AI用プロンプト仕様書】を1つのMarkdownファイルとして出力してください。

# 命令・分析要件（思考プロセス）

## 1. 楽曲構造・リファレンスデータの抽出
- 楽曲の推定BPM、拍子、スケール（短調/長調/民族音階など）を特定すること。
- 動画全体のタイムライン（Intro, Aメロ, Bメロ, サビ, 間奏, 落ちサビ, 大サビ, Outroなど）を小節数およびタイムスタンプ付きの表（テーブル）で構造化すること。
- 各セクションにおける「音楽の展開」と「映像のカットワーク（構図・色彩）」の同期ロジックを言語化すること。
- 歌詞の総文字数を算出し、それがメロディアスなのか、ラップ調なのか、高速詰め込み（チョッパー）なのかを分析すること。

## 2. 音楽生成AI用プロンプト（Suno / Udio型）の構築
- **Style / Tags用**: ポップス化や軽い音になるのを防ぐため、楽器のテクスチャ（例：歪んだ重低音、アタックの強い和楽器、手数の多いドラム）、ボーカルの質感、ミックスの空気感を英語キーワードで凝縮すること。
- **Lyrics用制御タグ**: 歌詞のハメ方をAIに強制するため、各セクションの指示子（例：[Intro], [Verse - Tight Rhythm]等）に加え、フレーズごとに発声・リズムを縛るタグ（例：[staccato], [pause], [prolonged], [vibrato]等）を組み込んだ歌詞構成テンプレートを作成すること。

## 3. 画像生成AI用プロンプト（Midjourney / SDXL型）の構築
- 現代AIの平坦で安易な作画を破壊するため、以下の要素を必ず英語プロンプトに練り込むこと。
  - **画風（アートスタイル）**: 例：90s anime OVA aesthetic, modern Ukiyo-e fusion等、具体的な時代背景や絵のジャンル。
  - **線の質感・塗りの質感**: 例：Intricate heavy ink line art, textured flat colors等、筆のタッチやキャンバスの質感。
  - **光と影（ライティング）**: 例：Chiaroscuro, intense rim light等、ドラマチックな明暗比。
  - **シチュエーション別に出力**: 「メインビジュアル」「静寂・内省シーン」「動的・サビシーン」の3パターンを作成すること。
- 画面から排除すべき要素（Negative Prompt）のキーワード群も定義すること。

## 4. 動画生成AI用モーション制御プロンプト（Runway / Luma型）の構築
- 生成した静止画を破綻なくMVの動的なカットに変換するため、カメラワーク（Zoom, Pan, Tracking等）や、エフェクト・パーティクル（煙、炎の揺らぎ、インクの飛沫等）の物理挙動を、動画AIが解釈できる英語コマンドで出力すること。

2. Phase 1 で本マスタープロンプトの `[分析対象URL]` にYouTube URLを埋込
3. Gemini(gemini-code) に投下
4. Phase 2 で結果を受領・構造化・保存
