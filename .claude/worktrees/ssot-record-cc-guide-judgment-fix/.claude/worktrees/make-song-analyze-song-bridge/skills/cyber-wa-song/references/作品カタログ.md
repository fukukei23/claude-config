# 作品カタログ（Phase 0 選択用）

サイバー和モダン3作品の楽曲構造・映像世界観・推奨ジャンル。Phase 0 で作品を選んだ後、本カタログから構造/BPM/映像世界観を提示する。

---

## 原点廻帰（Lunacy - 原点廻帰）

- **ジャンル**: ラウドロック×和楽器（アニソンコア）
- **BPM**: 135-140（ファスト）
- **拍子**: 4/4 / **スケール**: 陰音階ベースのマイナーキー
- **総小節数**: 約144（4分18秒換算）

### セクション構成
| セクション | 小節 | 役割 |
|---|---|---|
| イントロ | 8 | 静寂（鐘）からヘヴィリフへ爆発 |
| Aメロ | 16 | 音数を落としメロディと言葉を聴かせる |
| Bメロ | 8 | サビへのビルドアップ |
| サビ1 | 16 | 最大の盛り上がり・ツービート主体 |
| 間奏1 | 8 | ギター/和楽器ソロ |
| Aメロ2 | 8 | 1番より短縮・展開加速 |
| Bメロ2 | 8 | ビルドアップ |
| サビ2 | 16 | 2回目の感情爆発 |
| Cメロ | 16 | 落ちサビ・音数/テンポ感を落とす |
| 大サビ | 24 | 最大ピーク・ラスト8小節で転調拡張 |
| アウトロ | 12 | 激しい演奏維持・余韻収束 |

### サウンドロジック
- 和楽器（三味線・琵琶）の速弾きにディレイ/リバーブで高音域の金属アタックを空間配置
- ドロップチューニングのディストーションギターをベースと同期させて重厚ボトム
- 落ちサビはローパスフィルター（高音カット）で水面下/閉鎖空間を演出

### 映像世界観
青黒（静寂・内省）→ 赤炎（狂気・お祭り騒ぎ）へダイナミック変化するダーク和モダンファンタジー。般若の面 / 赤い満月 / 夜市の宴 / 浮世絵×ダークアニメ / 水墨画。

## 電子参拝（Japanese Ambient Lofi 🪷 電子参拝 / 仏よりAI）

- **ジャンル**: Lo-Fi Hip Hop（サイバー和モダン）
- **BPM**: 75-80（スロー）
- **拍子**: 4/4 / **スケール**: 和風ペンタトニック（都節・陰音階の現代アレンジ）
- **総小節数**: 約80（3分59秒換算）

### セクション構成
| セクション | 小節 | 役割 |
|---|---|---|
| イントロ | 8 | 環境ノイズ+エレピのコードのみ |
| テーマ1 | 16 | ドラムビートイン・ラップ調ボイス |
| フック1 | 8 | サビ相当・厚みのあるシンレイヤー |
| テーマ2 | 16 | ドラムの抜き差しで平坦回避 |
| フック2 | 8 | 2回目のリフレイン |
| ブリッジ | 8 | ドラム完全排除・アンビエントパッド |
| アウトロ | 16 | 楽器段階減少・フェードアウト |

### サウンドロジック
- Vinyl Crackle（レコード/線香の微小雑音）全編定常ミックス
- Wow & Flutter でエレピ/琴のピッチを微細揺らし経年テープ質感
- キック/スネアをジャストから後方へズラすレイドバックグルーヴ
- 高音域EQカット + お経サンプリングにグリッチ音でサイバー感

### 映像世界観
伝統仏教（寺院/読経/線香）× デジタル（AI/サブスク/NFT/通知）のサイバーパンク和モダン。AI仏（ホログラム/電子回路グリッド）/ QR決済のお賽銭箱 / ホログラム通知 / 蓮華上のデータ / 90sアニメ×サイバーパンク / VHS質感。

## 百鬼夜行（デジタル百鬼夜行）

- **ジャンル**: サイバー和モダンEDM（ハイパーポップ/エレクトロコア）
- **BPM**: 145-160（ファスト）
- **拍子**: 4/4 / **スケール**: 都節音階ベースのシンセベース主体マイナーキー
- **総小節数**: 約128-144

### セクション構成
| セクション | 小節 | 役割 |
|---|---|---|
| イントロ | 8 | 太鼓連打/尺八サンプリング+電子ノイズでビルドアップ |
| ドロップ1 | 16 | サビ相当・音圧最大化・4つ打ち駆動 |
| Aメロ | 16 | ハーフ（トラップビート）に落とし低音ボイス/ラップ |
| Bメロ | 8 | ライザー+スネアロールでエネルギー充填 |
| ドロップ2 | 16 | 変形ドロップ・三味線チョップ/スクラッチ付加 |
| Cメロ | 8 | ブレイクダウン・打楽器全停止・和楽器ソロで静寂 |
| ラストドロップ | 24 | 大サビ・1.5倍拡張・シンセ+歪みベース融合 |
| アウトロ | 8 | グリッチ音で唐突収束 |

### サウンドロジック
- 和楽器（三味線/太鼓）の高音域過剰ブースト+コンプレッサで均一化、16分単位でチョップし機械的和楽器音を構築
- Reese Bass & 808 にディストーション、サイドチェイン極端かけでうねり強調
- セクション接続部にテープストップ/バグ音のグリッチトランジション

### 映像世界観
太鼓連打×尺八×電子ノイズの高速ビートに百鬼夜行の混沌。和楽器の激奏アップ / 飛び散る赤い液体 / 群衆 / 鬼の形相。ダーク和モダン×サイバーパンク。
