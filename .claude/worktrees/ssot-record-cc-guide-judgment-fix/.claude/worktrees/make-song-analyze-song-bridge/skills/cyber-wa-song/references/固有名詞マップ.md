# サイバー和モダン固有名詞マップ（読み辞書）

> janomeデフォルト辞書で誤読・分割される固有名詞の**正しい日本語読み**。`scripts/kanji_to_hiragana.py` の `PROPER_NOUNS` と同期。janome は固有名詞を形態素分割するため（般若→はん+にゃ 等）、**本マップ＋正規表現先分割が必須**。

## 運用

- Phase 2（歌詞制作）で新しい固有名詞が登場した場合、**本マップ + `PROPER_NOUNS` の両方に追記**（同期必須）
- janome が正しく読む一般語はマップ不要
- カタカナ値を登録し、`kata_to_hira()` でひらがな化（`般若`→`ハンニャ`→`はんにゃ`）
