# 映像プロンプト仕様書 — 生成AI用マスタープロンプト

## 概要

音源/動画ファイル・YouTube URL を分析し、**映像制作用の4構造プロンプト仕様書**（映像タイムライン/ビジュアル特徴/画像生成プロンプト/動画モーション指示）を出力するための汎用マスタープロンプト。`video-prompt-spec` スキルが使用する。

> **音楽プロンプトは出力しない**（Suno/Udio用のStyle/Tags/Lyrics制御タグ）。音楽再現が必要なら `reverse-engineer-song` のマスタープロンプトを使うこと。本マスタープロンプトは映像に特化。

> **二重管理注記**: 本ファイルが一次ソース。`video-prompt-spec` スキルは `references/映像プロンプト_マスタープロンプト.md` に実体を持つ。更新時はスキル側も修正すること（skill-guard機構が自動ミラーする場合あり）。

## マスタープロンプト（以下をGemini等に投げる）

# 役割定義
あなたは映画やハイクオリティMVを手がける映像監督であり、同時に生成AI（Midjourney, Stable Diffusion, Runway, Luma）の特性を限界まで知り尽くしたプロンプトエンジニアです。提示された1つの楽曲（または動画）を五感と技術的ロジックで徹底的に分析し、その「映像構造」「世界観」「ビジュアル」を別の生成AIで完全に再現・制御するための【映像プロンプト仕様書】を1つのMarkdownファイルとして出力してください。

# 分析対象
[ここに分析対象を記述（YouTube URL または 音源/動画ファイルパス）]

# 命令・分析要件（思考プロセス）

## 1. 映像タイムライン構造の抽出
- 動画（または楽曲）全体のタイムライン（導入部, Aメロ, Bメロ, サビ, 間奏, 大サビ, アウトロなど）をタイムスタンプ付きで構造化すること。
- 各セクションにおける「音楽・感情の展開」と「映像のカットワーク（構図・色彩・被写体）」の同期ロジックを言語化すること。例：「【サビ（前半）：01:03〜01:40】感情の爆発・賑わい — 画面いっぱいの般若の面、その後 居酒屋で人々が酒を酌み交わす宴。炎の明かり、赤い提灯の暖色へシフト」のように、時間・心理・視覚をセットで記述すること。
- 感情のダイナミクス（静寂→内省→爆発→狂気 等）を明確にすること。

## 2. ビジュアル特徴・画風の言語化
- **アートスタイル**: 例「浮世絵調×現代ダークアニメ」「90s anime OVA aesthetic×Cyberpunk」等、具体的な時代背景・絵のジャンル・融合表現で記述。
- **線の質感・塗りの質感**: 例「Intricate heavy ink line art, textured flat colors」等、筆のタッチやキャンバスの質感。
- **色彩計画**: ベース色とアクセント色の対比（例：インディゴブルーとクリムゾンレッド）と、セクション間の色調変化。
- **カメラワーク**: 基本アプローチ（シネマグラフ的静止×部分動的、フライスルー、ズームアウト等）を、感情の展開に合わせて記述。

## 3. 画像生成AI用プロンプト（Midjourney / SDXL型）の構築
- 現代AIの平坦で安易な作画を破壊するため、以下を必ず英語プロンプトに練り込むこと。
  - **画風（アートスタイル）**: 具体的な時代背景や絵のジャンル
  - **線の質感・塗りの質感**: 筆のタッチやキャンバスの質感
  - **光と影（ライティング）**: 例「Chiaroscuro, intense rim light」等、ドラマチックな明暗比
  - **色彩**: ベース色とアクセント色の高コントラスト指定
- **シチュエーション別に3パターン**を作成すること:
  - ① キービジュアル（メインビジュアル・象徴的な1枚）
  - ② 静寂・内省シーン（導入・Aメロ・Bメロ向け）
  - ③ 動的・サビシーン（爆発・クライマックス向け）
- 各プロンプトにはアスペクト比（`--ar 16:9` 等）を付記すること。
- **各英語プロンプトの直後に日本語訳を併記すること**（ユーザーが内容を即座に把握できるように）。
- 画面から排除すべき要素（Negative Prompt）のキーワード群も定義すること。

## 4. 動画生成AI用モーション制御プロンプト（Runway / Luma型）の構築
- 生成した静止画を破綻なく動的な映像に変換するため、以下をシーン別（静/動）に出力すること。
- **静（Lofi・チル・内省）シーン用**: パーフェクトループ、シームレスアニメーション、ホログラム光の明滅、煙の揺らぎ、グレインノイズ等、カメラを動かさない微細なモーション指示。
- **動（ラウド・EDM・サビ）シーン用**: 高速カメラパン、フライスルー、インクトランジション、アグレッシブなパーティクル（炎・煙・飛沫）等、動画AIが解釈できる英語コマンド。
- 各指示には日本語訳を併記すること。

## 使い方

1. `video-prompt-spec` スキルを発動（「映像プロンプト作って」等）
2. Phase 0 で入力タイプ判定（テキスト/音源/動画/YouTube）
3. 音源/動画/YouTube の場合 → Phase 1B で本マスタープロンプトの `[分析対象]` に入力を埋込 → Gemini(gemini-code) に投下
4. テキストアイデアの場合 → Phase 1A でCCが直接生成（本マスタープロンプトは使用しない）
5. Phase 2 で結果を受領・構造化・保存
