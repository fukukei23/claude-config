# キャラクター辞書（Layer 1・AI非依存・確定）

> Phase 3（メロディ淘汰・曲先）以降で使う「歌唱キャラクター」を永続管理する辞書。
> 同じ曲・別曲で同じキャラクターを呼び出せるようにする（再現性・継続性）。
> 素材（声質・歌い方の定義）は本ファイル。コード進行・ジャンル構造は [L1]楽曲制作基礎_ジャンル別.md / [L1]音楽的キャラクター辞書.md を参照。

## なぜキャラクターを永続管理するか（背景・核心）

### 失敗パターン（2026-06-18 Phase 0.5 実測検証で発掘）
プロンプトで `(smooth melodic male rap)` と役割だけ書くと、AI が複数解釈して **複数の男性歌手キャラが混在**（KJ風＋Zeebra風が衝突）。さらに女性ボーカル枠も独立キャラとして同時生成され、結果 **3声の混在・性別不明瞭** になる。

### 対策: キャラクターを **人格化・永続化**
- **機能名**（例: `melodic_male_v1`）で AI に渡す → 同じキャラを別曲でも呼び出せる
- **ラベル**（例: `KJ-like`）で人間が把握 → 機能と一目で紐付け
- **歌詞では構造タグとして呼ぶ** → `[Verse 1]` 等と同じく **歌詞として歌われない** 想定

## 二層構造（あだ名 × 機能名）

```
【人間/設計者用ラベル】 ← あだ名・人間が見て一目でわかる
├ KJ-like  (melodic male)
├ ZB-like  (hard-hitting male)
└ ACO-like (soulful female)

【AI プロンプト・歌詞に渡す機能名】 ← システム的に安定・呼び出しキー
├ melodic_male_v1
├ hard_male_v1
└ soulful_female_v1
```

## 登録キャラクター（最小実装・2026-06-18 Phase 0.5 検証で確立）

```yaml
# characters/registry.yaml
characters:
  melodic_male_v1:
    label: "KJ-like"
    role_hint: "melodic male"
    voice_profile: |
      30s Japanese male, smooth melodic flow,
      breathy warmth with slight rasp,
      imperfect vibrato, intimate and youthful,
      mid-range tenor, raw 1990s hip-hop feel,
      natural human imperfections
    use_for: "叙情ラップ（Acoサビ前の Verse など）"
    first_used: "grateful-days-omage (2026-06-18)"

  hard_male_v1:
    label: "ZB-like"
    role_hint: "hard-hitting male"
    voice_profile: |
      30s Japanese male, hard-hitting classic boom bap flow,
      deep baritone with slight hoarseness,
      aggressive punch, raw street rap,
      imperfect cadence, vocal grit
    use_for: "ストリートラップ（Verse 3 など）"
    first_used: "grateful-days-omage (2026-06-18)"

  soulful_female_v1:
    label: "ACO-like"
    role_hint: "soulful female"
    voice_profile: |
      20s Japanese female, angelic soulful alto,
      breathy delivery with vocal grit,
      ethereal clarity, warm chest resonance,
      slight natural vibrato, intimate and dreamy,
      slight hoarseness, vintage analog warmth
    use_for: "サビ（Chorus）"
    first_used: "grateful-days-omage (2026-06-18)"
```

### 人間味語彙プール（Phase 1 プロンプト組立時に参照）

| 語彙 | 効果 | 用途 |
|---|---|---|
| `vocal grit` | 声のザラつき・砂っぽさ | ハードな声・男性 |
| `slight hoarseness` | 軽い嗄れ | 年齢感・ストリート感 |
| `imperfect vibrato` | 不完全なビブラート | AI完全ビブラート回避 |
| `intimate rasp` | 親密なラスピング | 親密性・人間の揺れ |
| `breathy voice` | 息っぽさ | 柔らかさ・近接感 |
| `raw 1990s recording feel` | 90年代 raw 録音感 | 当時の生々しさ |
| `vintage analog warmth` | アナログ機の温かみ | 年代感 |
| `vinyl saturation` | ヴァイナル・サチュレーション | ローファイ感 |
| `microphone proximity effect` | 近接効果 | 太い低音・近さ |
| `human imperfection` | 人間特有の不完全さ | 機械感の回避 |
| `natural human imperfections` | 自然体の揺れ | 全体適用可 |

## 歌詞での呼び出し（構造タグとして・歌われない想定）

```
[Verse 1]
[melodic_male_v1]
あさのひかりが　まどをぬけてく
いつものみちを　きょうもあるく
らじおからながれる　あのひのりずむ
ふとそらをみあげる　かぜをかんじて

[Verse 3]
[hard_male_v1]
...

[Chorus]
[soulful_female_v1]
このこえが　とどくのなら
...
```

→ `[Verse][Chorus]` 等の構造タグ同様に **歌詞として歌われない** ことが期待される（万一歌われたら新失敗パターンとして記録）。

## Phase での使い方

- **Phase 1（GMIV）**: prompt 側に `characters: melodic_male_v1 + hard_male_v1 + soulful_female_v1` の voice_profile を組み込む
- **Phase 3a（スキャット生成）**: lyrics 欄に `[melodic_male_v1]` 等の構造タグでキャラ指定
- **Phase 4（歌詞作成）**: 構造タグを残しつつ韻・音節設計
- **Phase 5（music-cover）**: 同じキャラを継続使用

## 拡張ルール

- 新キャラクター追加時: `label` + `voice_profile` を3文で記述、`first_used` を必ず記録
- バージョン管理: `melodic_male_v1` → `melodic_male_v2` で声質変更を明示（曲跨ぎで互換性切れる場合は v2 採用）
- 削除禁止: 一度登録したキャラは履歴保持（再有効化できるよう）

## 失敗パターン（昇格済み）

### FP-CHARA-001: 役割指定のみでは複数歌手キャラが衝突する
- 症状: `(male rap)` のような役割だけの指定で、AI 内部で複数男性歌手（KJ風＋Zeebra風）が同時生成され混在
- 修正: 機能名（`melodic_male_v1` 等）で **人格を固定**、ラベル（`KJ-like`）で人間側も把握
- 検証: 未検証（v3 で確認予定）
