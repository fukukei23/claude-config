# ラップの韻（ライム）技術

> 日本語ラップの韻は **子音より母音**。語尾の母音が揃えば韻になる。

## 大前提: 韻＝母音を揃える

```
例:「そうじん」= s/o ー/o j/i n
   「こうしん」= k/o ー/o sh/i n
   → 母音列 [o-o-i-n] 完全一致 → 4字韻（複韻）
```

## 韻の種類（置く場所）

| 種類 | 場所 | 特徴 |
|---|---|---|
| 脚韻（きゃくいん） | 行末尾 | 基本。聞き手が期待する着地点 |
| 頭韻（とういん） | 行先頭 | 思いつき順に埋めやすい。脚韻と併用で強力 |
| 内部韻（ないぶいん） | 行途中 | flowに躍動感 |

## 文字数による分類

| 呼び | 文字数 | 難易度 | 例 |
|---|---|---|---|
| 単韻 | 1字（語尾母音のみ） | ★ | だ/な/か |
| 2字韻 | 2字 | ★★ | そう/こう（o-u） |
| 3字韻 | 3字 | ★★★ | そうじ/こうし（o-u-i） |
| 4字韻（複韻） | 4字 | ★★★★ | そうじん/こうしん（o-u-i-n） |
| 多音節韻 | 5字〜 | ★★★★★ | Eminemは10音節スタッキング |

**「2〜4字」＝ 2字韻〜複韻が王道。**

## 完全韻 vs 母音韻（アソナンス）

| | 完全韻 | 母音韻（アソナンス） |
|---|---|---|
| 一致 | 子音+母音 | 母音のみ（子音は違ってOK） |
| 例 | そうじん/こうしん | はんじょう/かんう（部分一致） |
| 使いどころ | 決め手・サビ | flow内・緩い連関 |

**「母音踏みでもいい」＝ アソナンス活用可。完全韻が厳しい箇所は母音韻で繋ぐ。**

## 配置パターン

| パターン | 構造 | 効果 |
|---|---|---|
| 連韻（AABB） | 1=2 / 3=4 | 王道・安定 |
| 交韻（ABAB） | 1=3 / 2=4 | 流れる感覚 |
| 囲い韻（ABBA） | 1=4 / 2,3別 | 包み込む |
| ショットガン韻 | 1行内に複数 | テクニカル・攻め |
| 階段韻（スタッキング） | 3〜4行同韻連打 | 盛り上がり・サビ前 |
| バラ韻（飛び石） | 離れた行で同韻 | 伏線・統一感 |

## 日本語特有の注意

| 項目 | 扱い |
|---|---|
| アクセント（高低） | 母音同じでも高低違うと韻が薄れる。高低も揃えると強い |
| 「ー」（長音） | 直前母音の延長。「だー」=「a」 |
| 「っ」（促音） | 母音なし。韻にならないがリズムアクセント |
| 「ん」（撥音） | 母音「n」。4字韻の末尾に使いやすい（〜じん/〜しん/〜きん） |

## 作詞フロー（韻設計）

1. **テーマ語決定**（曹仁→「そうじん」「はんじょう」「かんう」）
2. **韻の核（母音列）を逆算**:「そうじん」= o-u-i-n
3. **同母音列の語をリスト**（こうしん/とうしん/ろうしん/ほうしん…）
4. **意味が通るように並べる**（韻優先で語を選ぶと意味が死ぬ→両立）
5. **脚韻を骨組み→頭韻/内部韻で肉付け**
6. **音数（モーラ）を行ごとに揃える**（flow安定）

## MiniMax music-2.6 適用

- AIは**ひらがな表記の母音列**しか読めない（漢字→誤読）
- 韻を踏ませるなら**歌詞をひらがなで書き、意図する母音列を揃える**
- AIが韻を「認識」するわけではないが、**母音が揃っていれば歌唱時に自然に韻が響く**
