## 1. 核心公式（4/4拍子）

```
1小節の長さ(秒) = (60 ÷ BPM) × 4
秒数            = 小節数 × 4拍 × (60 ÷ BPM)
小節数          = (分数 × BPM) ÷ 4
```

## 2. テンポ×曲長 連動表

| 小節数(4/4) | BPM120(速) | BPM90(中) | BPM70(遅) |
|---|---|---|---|
| 8小節（フック） | 16秒 | 21秒 | 27秒 |
| 16小節（Verse） | 32秒 | 43秒 | 55秒 |

## 4. ジャンル別標準曲構造

### ヒップホップ/トラップ
```
Intro(4-8) → Verse1(16) → Chorus(8) → Verse2(16) → Chorus(8) → Verse3(16) → Chorus(8) → Outro(8)
業界標準: 16小節Verse / 8小節Chorus を3セット
```

### J-POP
```
Intro → Aメロ(8-16) → Bメロ(8) → サビ(8-16) → 間奏 → A2 → B2 → サビ → Cメロ(落ちサビ) → 大サビ → Outro
```

### EDM
```
Intro(8) → Build Up(8) → Drop1(16) → Aメロ(16) → Bメロ(8) → Drop2(16) → Breakdown(8) → Last Drop(24) → Outro(8)
```

### K-POP
複数パート構成＋英語フレーズ混入。Verse1(ラップ)→Verse2(ボーカル)→PreChorus→Chorus→RapBreak→Chorus 等の多变な展開。

### Lo-Fi Hip Hop
4-8小節のコード進行ループを基盤。Intro→Theme1(16)→Hook(8)→Theme2(16)→Hook(8)→Bridge→Outro。

## 5. 構造タグ14種（MiniMax music-2.6 公式）

```
[Intro] [Verse] [Pre Chorus] [Chorus] [Interlude] [Bridge]
[Outro] [Post Chorus] [Transition] [Break] [Hook] [Build Up]
[Inst] [Solo]
```

⚠️ music側は**スペース区切り**（`[Pre Chorus]`）。lyrics側はハイフン（`[Pre-Chorus]`）。混同注意。

## 6. 感情曲線（Emotion Arc）設計 ※核心

曲は「感情の旅」。構造と並んで**感情がどう動くか**を必ず設計する:

| セクション | 感情の例 |
|---|---|
| Intro | 世界観提示・静寂・不穏 |
| Aメロ | 語り・日常・抑圧 |
| Bメロ | 葛藤・高まり・予感 |
| サビ | 爆発・解放・希望・決意 |
| Cメロ/Bridge | 転換・内省・静寂 |
| 大サビ | 最高到達・転調・カタルシス |

**設計例**: 不穏(Intro) → 抑圧(A) → 葛藤(B) → 解放(サビ) → 内省(C) → カタルシス(大サビ)

> 構造タグだけでは「正しいが心に響かない」曲になる。感情曲線を併記することで「最高の曲」に近づく。
