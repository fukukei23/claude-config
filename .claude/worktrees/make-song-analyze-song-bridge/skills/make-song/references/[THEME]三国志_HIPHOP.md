## 作曲の型

| 項目 | 内容 |
|---|---|
| **推奨ジャンル** | 和風HIPHOP / 中華風HIPHOP / トラップ / ドリル / オーケストラHIPHOP / ブームバップ / グレイトフル・デイズ風 / ヌメタルHIPHOP |
| **BPM** | 70-115（ラップ・ストーリー重視・語り系） |

## 武将カタログ（作曲向けサマリ）

曹操 / 曹仁 / 関羽 / 張飛 / 趙雲 / 諸葛亮 / 呂布 / 周瑜 / 劉備 / 司馬懿
→ 各武将の**史実エピソード**（曹仁→樊城籠城戦 等）がテーマの核。詳細は上記カタログ参照。

## Phase 0 「三国志HIPHOP」選択時の進め方

1. 武将選択（`武将カタログ.md` から）
2. エピソード/戦の確定
3. `[L1]` 基礎知識（プロンプト技法・構造理論・楽曲制作基礎・日本語歌詞）＋ 本テーマ資産 で GMIV/構造/歌詞/プロンプトを構築
4. 発音は固有名詞マップ（中国史の読み）＋ `[L1]日本語歌詞技法`

> **映像も欲しい時**: `sangoku-song` スキルを使用（曲+画像+動画の統合ウィザード）。本テーマは「曲+詞」専業。
