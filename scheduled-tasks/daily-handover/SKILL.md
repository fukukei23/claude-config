毎晩22時に実行される引き継ぎ文書の自動生成タスクです。

## 目的
その日の作業内容をまとめ、次回セッションへの引き継ぎ文書を自動生成して保存する。

## 手順

1. **今日の日付を取得**
   - 現在の日付を `YYYY-MM-DD` 形式で確認する

2. **ワークスペース状態の確認**
   - `C:\Users\User\workspace\_INDEX.md` を読み込み、アクティブなプロジェクト一覧と状態を把握する

3. **本日の作業ファイルを収集**
   - `C:\Users\User\workspace\active\` 配下で本日更新されたファイルを列挙する（Bashで `find` または `ls -lt` を使用）
   - 各プロジェクトのgitリポジトリがあれば `git log --oneline --since="today"` で本日のコミット一覧を取得する

4. **引き継ぎ文書を生成**
   以下の形式で Markdown ファイルを作成する：

   ```markdown
   # 引き継ぎ文書 YYYY-MM-DD

   ## 本日の作業サマリー
   （作業内容を3〜5行で要約）

   ## 作業したプロジェクト
   （プロジェクト名と作業内容）

   ## 本日更新したファイル
   （ファイルパスと変更概要）

   ## 未完了タスク・課題
   （継続作業が必要な項目）

   ## 次回セッションへの申し送り
   （次回開始時に確認すべき事項）

   ## プロジェクト状態スナップショット
   （_INDEX.mdから抜粋）
   ```

5. **ファイルを保存**
   - 保存先: `C:\Users\User\workspace\handover\YYYY-MM-DD_daily_handover.md`
   - ディレクトリが存在しない場合は作成する

6. **古い引き継ぎ文書の整理**
   - 30日以上前の引き継ぎ文書があれば、ファイル名一覧をコメントとして末尾に記録する（削除はしない）

## 成功条件
- `handover/YYYY-MM-DD_daily_handover.md` が正常に作成されること
- ファイルに本日の日付と作業内容が含まれること

## 注意事項
- ファイルが存在しない・読めない場合はスキップして続行する
- エラーが発生しても部分的な情報で文書を作成する
- パスはWindows形式（バックスラッシュ）とWSL形式（スラッシュ）の両方を考慮する
