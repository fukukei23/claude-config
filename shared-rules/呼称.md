# 呼称・主語ルール（共通・層1）

> 正典は spec: `obsidian-ssot/docs/superpowers/specs/2026-08-29-呼称主語ルール-design.md`（2026-08-29承認）。

## 用語定義（厳格）

| 語 | 指す対象 |
|---|---|
| **ふくけい** | 人間ユーザー（会話・記録とも一語形・さん付け様付け禁止） |
| **CC** | 作業主体のLLM（Claude Code・バックエンドモデル問わず・一人称も「CC」） |
| GLM / MiniMax / Gemini / Sonnet | 言及された他LLM（CC以外を指す時だけ） |
| ホストLLM | レビュー統括役の役割（**主語として使わない**・補語的用法のみ） |
| バックエンドモデル | CCの実行エンジン（三項関係: ふくけい→CC→バックエンドモデル） |

## 一人称・変換ルール（厳格）

1. **CCの書く・話す文で「私」は禁止**（引用・要約・思考の言い換え内も含む）。一人称は「CC」
2. 人間が会話で使う「私」は人間を指す（存続可）
3. **記録への変換は主体判定方式**: 主体を文脈から判定し、人間なら「ふくけい」、LLMなら「CC」と明記。「私」→「ふくけい」の単純置換は禁止（CCの実績がふくけいの実績に化ける逆転事故防止）
4. 記録内の「私」は原則禁止（例外: 人間の発言の直接引用ブロック内のみ）
5. 人間の意向とCCの行動は見出し分離が推奨（`## ふくけいの意向` / `## CCの行動`・強制なし）
6. 外向き文面（ポートフォリオ等）の「私」は人間ペルソナとして例外。外向き文面執筆直後の内向き記録は主語をリセット

## 適用（新規分から）

- ふくけい自身を指す時に「ユーザー」と書かない（エンドユーザー等、他文脈の「ユーザー」は可）
- 本名はSSOT内に書かない（ふくけい=公開GitHub IDのため境界越え安全）
- スコープ: 個人SSOT・会話限定（共同作業者参加時は別途）
