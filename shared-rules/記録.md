# 記録ルール（共通・層1）

> **本ファイルは層1（CLAUDE.md が @ include・毎回読込）なので要点のみ。詳細手順は `~/.claude/skills/ssot-record/SKILL.md`（層2・スキル発動時読込）が正典。**

## 核心（厳格）

- **記録は `ssot-record` スキル経由のみ**。手動 Write/Edit での `01_DECISIONS/` 作成は PreToolUse hook(`enforce-ssot-record.sh`)がブロック（`/tmp/ssot-record-active` フラグ時のみ許可＝スキル経由のみ通る）
- **新しいトピックに移る前に必ず記録**（「後で書く」禁止）
- **自発的発動**: ふくけいが「記録して」と言わなくても、タスク完了・トピック区切りで `ssot-record` スキルを Skill ツールで発動
- **日記に技術詳細を直書きしない**（サマリー+リンクのみ）・既存日記に追記（上書き禁止）

## 連携更新（ssot-record スキルが自動担保）

`01_DECISIONS/<project>/YYYY-MM-DD_<description>.md`（詳細・frontmatter）・`_INDEX.md`（末尾テーブル1行）・`自動化.md`（tagsに「自動化」含む時）・`10_DAILY/YYYY-MM-DD.md`（サマリー+リンク）・CCガイド（Claude Code関連時）・**00_SYSTEMハブ**（tags/内容→ハブマッピング.md で機械判定）

### 00_SYSTEMハブ新設時はハブマッピング.md更新（層2・厳格）
- 00_SYSTEM に新規ハブ（まとめページ）を作る時は**必ず `00_SYSTEM/ハブマッピング.md` に1行追記**（必須タグ・追加タグ・ハブ・追記セクション・重要度）
- **未登録のハブは ssot-record が更新対象から漏れる**（循環的抜け・2026-07-07 セキュリティ設定ハブ見逃し事故の教訓）

## 構想段階の合意の永続化（厳格）

「合意成立・spec未作成」の中間状態の**設計判断（構想）**は `バックログ.md` 該当タスク直下の 📝WIPメモで永続化（真実のソースを増やさない・タスクと運命共同体）。

- **発動タイミング**: 明示キーワード（「これ残して」「決定事項にして」「構想メモ」）・sentaku/brainstorming 終了時に spec 未出力なら「代わりに構想を残しますか?[y/N]」
- **能動検知は廃止**（誤検知/アラート疲労回避・迷ったら出さない）
- **振り分け**: 設計判断含む=構想(📝WIP)・単一アクション完結=バックログ通常行・実装詳細仕様=spec直行・判定不能→構想
- **ライフサイクル**: spec化→リンク置換・タスク破棄→メモも消える・30日滞留→破棄候補フラグ

### 構想メモ形式（軽量）
```markdown
  - 📝 構想(YYYY-MM-DD): <方針1-2行>
    - 経緯: <候補/選択理由/却下>
    - 次タスク: <承認済・設計未着手の内容>
```

## 期限付き先送りはdurable cronリマインダー化＋Triage整合チェック（厳格・2026-08-29）

「N日後に判定」「観察期間満了」等の**期限付き先送り**を記録・バックログ・会話中に書いたら:
1. **相対表現（○日後等）はその場で具体日(YYYY-MM-DD)に変換**
2. **CronCreateでdurable one-shotリマインダーを即設定**（満了日発火・:00/:30回避=全クライアント発火集中を避けるため・promptは冪等に書く）
3. **発火prompt必須5要素**: ①判定材料の取得コマンド ②判定基準（閾値・期待値）③達成時の次アクション ④背景1行 ⑤正典リンク
4. **cron IDをバックログ該当行/進捗メモに追記**して紐付ける
5. **クローズ時はCronDelete**: [x]完了/放棄/却下=削除・保留=削除+再開時に再登録・別タスク統合=新dueに再設定

期限不確定の「自然発火待ち」は対象外（Daily Triageが拾う）。**機械検証（層2）**: Daily Triageが「期限付き`[ ]`行でcron ID未記載」および「due日超過」を警告（LLMの実行忘れを翌朝検知）。詳細スキーマはssot-record SKILL.md（`due:`/`cron_id:`形式）を参照。

## スキル作成後の必須フロー（厳格）

新しいスキルを作成・完成させたら以下を必ず実施（「後でやる」禁止）:
1. **概要を整理して伝える**（スキル名・できること・いつ使うか・トリガーワード）
2. **関連ガイドに追記**（claude-code-guide 等・スキル紹介セクション追加）
3. **SSOT に記録**（`ssot-record` スキル経由・`01_DECISIONS/claude-code/YYYY-MM-DD_スキル名-skill-作成.md` + 日記）
4. **skills-custom/ に保存**（公式プラグインスキルをカスタマイズした場合のみ `~/projects/claude-config/skills-custom/`）
