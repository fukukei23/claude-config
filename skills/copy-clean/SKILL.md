# copy-clean — コピペ前整形チェック

> 3種事故の再発防止（2026-08-30実発）: ①マークダウン残骸（`**`）が表示欄にそのまま出る ②本文を別欄（500字上限）に誤貼り ③文字数超過。

## 鉄則（必須・省略禁止）

1. **対象欄を復唱して固定**: ユーザー発話から対象欄名をそのまま復唱し、プロファイル表と照合。**曖昧・未登録欄は絶対に推測で進めず停止**し、編集画面の表示値を確認して教えてもらう（沈黙通過禁止・3機レビューMiniMax#2/#3）。
2. **出品画面の表示値を正**: 下表と画面表示が不一致なら、画面値で実施し**この表（`copy_clean_profiles.json`）をその場で更新**。
3. **機械検証の証跡を必ず添付**: 完了報告に「入力欄／出力欄／差異の有無／実測文字数／チェック生出力」を貼る。
4. **機械検証の限界を明記**: 本検証は「整形の証明」であって「欄取り違え・文面前後矛盾の証明」ではない。最終確認はユーザーの目視を促す。

## フロー（5ステップ）

1. **欄の復唱と固定**: 「対象欄は◯◯（上限N字）で良いですか？」→ ユーザー確認で固定・以後の判定は固定値のみ
2. **整形**: マークダウン記法の除去・欄向け文面への整形（**自動修正の対象はエラー扱い残骸のみ**）
3. **検証**: 整形済みテキストを `/tmp/copy_clean_target.txt` に保存→下記コマンドを**逐語**実行→一時ファイル削除
4. **出力**: コピペ対象は**1コードブロックのみ**（複数欄は複数ブロック）。証跡はブロックの**外**に記載（ヘッダーごとコピペ事故の防止）
5. **完了報告テンプレ**: `入力欄=○○／出力欄=○○／差異=なし／実測N字/上限M字／チェック生出力（コピペ）`

## 検証コマンド（逐語実行・標準ライブラリのみ）

```bash
python3 ~/.claude/scripts/obsidian/copy_clean_check.py <profile> <欄名> /tmp/copy_clean_target.txt
echo "EXIT=$?"
```

- 終了コード: `0`=合格 / `1`=文字数超過またはエラー扱い残骸あり / `2`=profile・欄名不明（停止して確認）
- エラー扱い残骸（必ず除去）: `**` `__` ```` ``` ```` `[](` HTMLタグ
- 警告扱い（自動修正せず報告のみ・過剰修正で本文を壊さない）: 行頭`#`・`>`・`- `・`1. `
