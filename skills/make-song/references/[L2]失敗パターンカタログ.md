## 既知の失敗パターン（実測）

### 1. 漢字歌詞 → 誤読・造語生成
- **症状**: 「樊城」→「まいふせつ」、「不屈」→「ふこつ」誤読、造語「すがわだ」生成
- **原因**: MiniMax が漢字を読めない
- **対策**: **ひらがな化必須**（→ `[L2]発音問題_MiniMax固有.md`）

### 2. 楽器指定過多 → 全部が薄くなる
- **原因**: 楽器5個以上で AI が混乱
- **対策**: **楽器2-4個制限**（`[L1]プロンプト技法.md` §4）

### 3. `[Drop]`タグを非EDMで使用 → dubstepワブル混入
- **原因**: `[Drop]` はEDM専用
- **対策**: folk/ballad では使わない

### 4. `play_audio` 使用 → 300sタイムアウト・ユーザー停止不能
- **原因**: MCP play_audio の仕様（E2E検証で判明）
- **対策**: **play_audio 使わない**・生成ファイルパスを提示し**ユーザー手動再生**

### 5. 助詞「は」放置 → 「ha」と誤発音
- **原因**: MiniMax が助詞「は」を「ha」と読む
- **対策**: **「は→わ」全適用**（`[L1]日本語歌詞技法.md` §2）

### 6. `[Verse]`単独（番号なし） → Verse3回が2回に圧縮
- **原因**: MiniMax が `[Verse]` のみを同一構造と認識し圧縮
- **対策**: **`[Verse 1][Verse 2][Verse 3]` 番号付き**（`[L2]MiniMax実測知見.md` §3）

### 7. 良い回を再生成で消失 → 曲調劣化
- **原因**: music-2.6 は非決定的（seed指定不可）。歌詞修正で再生成すると曲調も変わる
- **対策**: 良い回を即 `music_cover_preprocess` 保存 → music-cover で歌詞だけ修正
