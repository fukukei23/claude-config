| **B. 中高音使用率**（新） | ウィスパー低音偏り | A4(440Hz)以上の音域使用 ≥ 50% |

## 軸A: 音節密度（既存・維持）

歌詞をメロディに載せる際、**1秒あたり音節数（≒文字数/秒）** に上限を設けることで、ラップ調・早口を回避し「人間が歌える速度」を担保する指標。

| 領域 | 1秒あたり音節数 | 用途 |
|---|---|---|
| ✅ 安全域 | 8音節/秒以下 | 歌もの・J-Rock歌もの・人間が歌える速さ（**推奨**） |
| ⚠️ 警告域 | 8〜10音節/秒 | メロディックラップ寄り・許容（ユーザー指示が「ラップ寄り」の場合のみ） |
| ❌ 禁止域 | 10音節/秒超 | ラップ調・人間離れ（避ける） |

### BPM連動の計算

4/4拍子の1小節 = `60 / BPM × 4` 秒。

```
8小節 = 1920 / BPM 秒
16小節 = 3840 / BPM 秒
```

各セクションの歌詞について:

```
音節数/秒 = Σセクション内行の文字数 ÷ セクション秒数
```

### 簡易ルール（手計算用）

- **1行 18文字以下** を目安にする
- 8小節・BPM=100の場合: 19.2秒 に 4行 で安全域（4行 × 18字 = 72字 ÷ 19.2 ≒ 3.75音節/秒・余裕）
- 16小節・BPM=145（v1の失敗例）の場合: 26.5秒 に 4行 = 4行×18字=72字 ÷ 26.5 ≒ 2.7音節/秒（安全）だが v1 は各行 22-25文字 = 危険域

## 軸B: 中高音使用率（新規・2026-07-11追加）

**目的**: ボーカルが低音域（ウィスパー）に偏るのを防ぐ。メロディの最低音域（A3=220Hz）に対する高音域（A4=440Hz以上）使用比率を計測。

### 判定基準

| 領域 | 中高音使用率 | 用途 |
|---|---|---|
| ✅ 推奨 | 50%以上 | 通常の歌もの（中高音域がメロディの核） |
| ⚠️ 警告 | 30〜50% | バラード・語り寄り（許容） |
| ❌ 禁止 | 30%未満 | ウィスパー低音偏り・抑揚なし（v2失敗パターン） |

### 計測方法（実装）

現状は生成後に評価するため、**プロンプト側で予防的に制御**:

- **声質プロファイル**: 「whisper-to-belt contrast」を明記し、**belt（中高音）が主**であることを明示
- **具体語**: 「中高音域で歌う」「A4以上を多用」「サビでベルティング」等をプロンプトに含める
- **生成後のチェック**: MusicAnalysis APIが利用可能なら、最低音/最高音を取得して自動計算（Phase 1では未実装）

### プロンプト例（v3以降）

```
【ボーカル】男性ハスキー tenor、melodic singing style、rap禁止・朗読禁止、
**中高音域(A4以上)を主軸に歌う・低音ウィスパーに偏らない・whisper-to-belt contrast（belt=主）**、
contemporary Japanese pop timbre、slight nasality、BPM 98、Dm
```

## 軸C: 抑揚幅スコア（新規・2026-07-11追加）

**目的**: メロディの音程の上下幅が狭く、平板（抑揚なし）になるのを防ぐ。

### 判定基準

| 領域 | 音程の幅 | 用途 |
|---|---|---|
| ✅ 推奨 | 5音以上 | 通常の歌もの（メロディに動きがある） |
| ⚠️ 警告 | 3〜5音 | 語り寄り・静かなバラード（許容） |
| ❌ 禁止 | 3音未満 | 平板メロディ・抑揚なし（v2失敗パターン） |

### 計測方法（実装）

MusicAnalysis APIやメロディ抽出ツールが利用可能なら、MIDI音程の最大-最小で自動計算。Phase 1では未実装で、**プロンプト側で予防的に制御**:

- **プロンプトに「メロディに動きをつける」旨を明記**
- **具体語**: 「メロディーの起伏を5音以上確保」「サビで跳躍」「AメロBメロで順次進行+サビで跳躍」等
- **生成後のチェック**: イヤホンで聴いて「単調に感じる」なら抑揚幅不足の可能性大

### プロンプト例（v3以降）

```
【メロディー】音節密度8音節/秒以下、**メロディーの起伏を5音以上確保**、
サビで音程の跳躍、AメロBメロは順次進行寄り+サビで跳躍、
低音ウィスパーに偏らない・中高音域(A4以上)使用率50%以上
```

## 📊 3軸統合チェック（Phase 1）

```
✅ すべて安全域通過 → 生成OK
⚠️ 1軸が警告域    → 再生成（プロンプト微修正・1変数変更法）
❌ 1軸が禁止域    → メロディ/歌詞再設計（コスト高・根本対処）
```

### v2楽曲「祭礼前夜」での実測

| 軸 | 実測値 | 判定 |
|---|---|---|
| A. 音節密度 | 5.4〜6.9 | ✅ 安全域 |
| B. 中高音使用率 | **低い（低音ウィスパー偏り）** | ❌ 禁止域 |
| C. 抑揚幅 | **狭い（抑揚なし）** | ❌ 禁止域 |

→ 音節密度Aだけ合格でも、B・Cが禁止域で「ラップ調ウィスパー低音」になった。多次元判定の必要性が実証された。

## 🛠️ チェックツール実装（Phase 1・Python）

`scripts/check_song_quality.py` を新規実装予定:

```python
"""
メロディ品質3軸チェッカー
- 軸A: 音節密度
- 軸B: 中高音使用率（プロンプト評価 or MusicAnalysis）
- 軸C: 抑揚幅スコア（同上）

Phase 1では軸A（歌詞ファイルから機械計算）のみ実装。
軸B・Cはプロンプト評価 or 生成後手動評価。
"""

def check_syllable_density(lyrics_path: str, bpm: int) -> dict:
    """軸A: 音節密度計算"""
    import re
    content = Path(lyrics_path).read_text()

    # セクション分割
    sections = re.split(r'\[(\w+)\]', content)

    results = {}
    for i in range(1, len(sections), 2):
        section_name = sections[i]
        section_text = sections[i + 1]
        lines = [l for l in section_text.splitlines() if l.strip()]
        total_syl = sum(
            len(re.sub(r"[、。、 「」『』()（）\[\]/…\s]", "", l))
            for l in lines
        )
        # セクション秒数推定（デフォルト8小節）
        section_seconds = 8 * 60.0 / bpm * 4.0
        density = total_syl / section_seconds
        results[section_name] = {
            'syllables': total_syl,
            'seconds': section_seconds,
            'density': round(density, 2),
            'verdict': 'safe' if density <= 8 else ('warning' if density <= 10 else 'forbidden')
        }
    return results
```
