## 概要

歌詞をメロディに載せる際、**1秒あたり音節数（≒文字数/秒）** に上限を設けることで、ラップ調・早口を回避し「人間が歌える速度」を担保する指標。

## 指標

| 領域 | 1秒あたり音節数 | 用途 |
|---|---|---|
| ✅ 安全域 | 8音節/秒以下 | 歌もの・J-Rock歌もの・人間が歌える速さ（**推奨**） |
| ⚠️ 警告域 | 8〜10音節/秒 | メロディックラップ寄り・許容（ユーザー指示が「ラップ寄り」の場合のみ） |
| ❌ 禁止域 | 10音節/秒超 | ラップ調・人間離れ（避ける） |

## BPM連動の計算

4/4拍子の1小節 = `60 / BPM × 4` 秒。

```
8小節 = 1920 / BPM 秒
16小節 = 3840 / BPM 秒
```

各セクションの歌詞について:

```
音節数/秒 = Σセクション内行の文字数 ÷ セクション秒数
```

## 簡易ルール（手計算用）

- **1行 18文字以下** を目安にする
- 8小節・BPM=100の場合: 19.2秒 に 4行 で安全域（4行 × 18字 = 72字 ÷ 19.2 ≒ 3.75音節/秒・余裕）
- 16小節・BPM=145（v1の失敗例）の場合: 26.5秒 に 4行 = 4行×18字=72字 ÷ 26.5 ≒ 2.7音節/秒（安全）だが v1 は各行 22-25文字 = 危険域

## 計算式（Python・実装案）

```python
import re

def line_syllables(line: str) -> int:
    line = line.strip()
    if not line:
        return 0
    line = re.sub(r"[、。、「」『』()（）\[\]/…\s]", "", line)
    return len(line)

def syllables_per_second(lyrics_section: str, bpm: int, bars: int = 8) -> float:
    lines = [l for l in lyrics_section.splitlines() if l.strip()]
    total = sum(line_syllables(l) for l in lines)
    section_seconds = bars * 60.0 / bpm * 4.0
    return total / section_seconds

# 使い方
lyrics = """月が照らす はじまりの鐘
誰もいない 始発前の街角で
昨日までの自分を置き去りに歩く
新しい自分に出会うため"""

print(syllables_per_second(lyrics, bpm=98, bars=16))  # → 5.4（安全域）
```

## 音節密度チェック

各セクション（Intro/A/B/C/Big Chorus）の歌詞について、
BPM から 1秒あたり音節数を算出し、以下を遵守すること：

- ✅ 安全域: 8音節/秒以下（推奨・歌もの）
- ⚠️ 警告域: 8〜10音節/秒（メロディックラップ寄り・許容）
