# プロンプト技法（Layer 1・AI非依存・確定）

> **信頼度: 高**（Suno/Udio/Stable Audio 複数ソースで裏打ちされた汎用音楽プロンプト理論）。AI が変わっても通用する。
> 出典: Suno Architect / Udio公式 / Stable Audio 2.5 / SSOT `2026-06-14_ZAI転写API解明...md` §3.2

---

## 1. GMIV順序プロンプト構造

**Genre → Mood → Instrumentation → Vocal** の順。最も支配的な要素を先頭に。順序が品質に直結する。

```
<ジャンル+時代>, <ムード/情景>, <楽器>, <ボーカル指定>, <テンポ>
例: 90s Garage rock, raw and aggressive, distorted bass, room mic drums, shouted male vocals, 120 BPM
```

## 2. 抽象語NG / 具体語推（決定的差）

- ❌ `Rock` → 10回生成して共通性なし
- ✅ `90s Garage rock, raw and aggressive, distorted bass, room mic drums, shouted male vocals, lo-fi production` → 10回すべて共通アイデンティティ

**教訓**: ジャンル名1語ではなく、テクスチャ・奏法・ミックス質感まで英語キーワードで凝縮する。

## 3. 「ジャンル+時代」で精度劇上

`[1980s Synthwave]` `[90s Boom Bap]` `[70s Disco]` `[2010s Trap]` 等。時代を添えるだけで音色が絞られる。

## 4. 楽器は メイン2-3 + 補助1-3 = 計3-6個（ジャンルで変動）

- **メイン音源(2-3)**: 曲の骨・必ず目立つ（リズム隊=ドラム/ベース + コード楽器=ピアノ/ギター）
- **補助音源(1-3)**: 厚み・彩り（synth pad・ストリングス・ソロ・ライザー）
- メインを厳選して**音源順序の先頭**に書き、補助で厚みを出す
- **ジャンルによって構成・数は変動**（→ `[L1]楽曲制作基礎` のジャンル別「楽器構成」参照）
- 実態: トラップ/R&B/Lo-Fi は3、J-POP/ロック は3-5、EDM/アニソン は4-5

## 5. 音源順序（Stable Audio知見）

**重要な音源を先に**、質感・プロダクション特性を後に:
```
Distorted 808 bass, trap hi-hats, dark cinematic synth pads, reverb-drenched vocals
```

## 6. 構造タグは Style より10倍強力（公式検証）

メタタグなしで3分曲を任せると、AIが6-8回構造を推測して破綻する。構造タグ（`[Verse][Chorus]`等）で明示制御。→ 詳細は `[L1]構造理論.md`

## 7. ネガティブ制御は信頼性低

Style欄の `no drums` 等は無効なこと多い。公式 Exclude 欄を使うか、使わずに肯定表現で組む。

## 8. ジャンルスタッキング

単一ジャンルより影響関係を書く:
```
Lo-fi hip hop with R&B influences
```

## 9. 1変数ずつ変更してテスト（科学的手法・要因孤立）

複数変数を同時に変えると原因が分からない。曲直しは**1変数のみ変更**して生成→比較。→ Phase 4 で実践。

## 10. 記法の使い分け（実証度で判定）

| 記法 | 例 | 実証度 | 位置付け |
|---|---|---|---|
| **括弧 `(text)`** | `(female lead vocal)` `(male rap feature verse)` | **MiniMax実証済**（v10男女デュオ） | 主軸・backing/response/ad-lib |
| **コロン `[Verse: ...]`** | `[Verse: whispered vocals, acoustic guitar only]` | Suno専用の可能性・**MiniMax未検証** | 試す価値あり・「未検証」ラベル |

> コロン記法が MiniMax で効くかは未検証。使う時は効果を実測し、効けば `[L2]MiniMax実測知見.md` へ昇格。

## Phase 1/3a での使い方

- Phase 1 の **GMIV** 収集にこの順序を適用
- Phase 3a の**音楽プロンプト組立**で、上記10技法を反映した英語プロンプトを生成
- 具体語・時代付き・楽器2-4個・音源順序・構造タグ を必ず盛り込む
