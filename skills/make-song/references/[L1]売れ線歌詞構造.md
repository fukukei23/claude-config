# 売れ線歌詞構造（Layer 1 - 確定・汎用）

## 共通ルール

### 1. サビ構造

**決定づけ**
- 「さぁ～だ」「やっぱり～だ」でモチーフ再確認
- 「～だろ」「～だ」の終止形で決定

**呼びかけ**
- 「踊りませんか？」「笑え、笑え」「酔え、酔え」
- 「泣いて、笑って、息して」「進め、果て、越えて」

**感情**
- 「それが生きる証」「それが本当の形だろ」「それが答えだろ」

---

### 2. 単語のチョイス傾向

**感情単語**
- 鼓動、震え、嘘、痛み、夢、生きる証、夜、影、光、僕/俺

**動詞**
- 踏みしめる、立つ、越える、信じる、歩く、消える、咲く、呼ぶ

**否定・肯定**
- いらない、必要ない、そうだろ、大丈夫、どうせ、ここにある

**呼びかけ**
- さぁ、笑え、酔え、踊りませんか？、聴いて、見て

---

### 3. 構造パターン

**基本構造**
```
Aメロ（16）: 読み上げ系・語り系
Bメロ（8）: ビルドアップ・感情の高まり
サビ（16）: 最大クライマックス（4反復）
[Break]（4-8）: 一拍リセット・呼吸
Cメロ（16）: 深化・余韻
大サビ（24）: ユニゾン→ハモリ→重奏
アウトロ（8-12）: 残響収束
```

**サビ反復構造**
```
[決定] 「さぁ原点廻帰だ」
[肯定] 「胸に刻め」「ここにある」
[呼びかけ] 「酔え、酔え」「泣いて、笑って、息して」
[感情] 「それが生きる証」
[再反復] 「さぁ～だ」でモチーフ決定
```

---

### 4. 原点回帰テーマ表現

**表現方法**
- 「はじまりの鐘」「午前零時」「無限回廊」
- 「繰り返す」「戻る」「起きる」「目が合う」
- 「失くしたはずの声」への言及
- 「どうせ終わりなら」「自分で歩け」と覚悟

---

### 5. PC用語排除実例

| × PC用語 | ✓ 情緒的表現 |
|---------|------------|
| ゼロ | 零（ゼロ）・記憶・起点・穴 |
| バイナリ | 心の種・本質・暗号 |
| コード | 調べる・繋ぐ・始まり・約束 |
| プログラム / コンピュータ | 歩み・道・道標・記憶 |
| データ | 記録・痕跡・残響 |
| バグ | 傷跡・歪み・隙間 |
| アプリ / ソフトウェア | 世界・記憶・思い出 |

---

### 6. 売れ線テンプレート

**テンプレートA（原点回帰）**
```
[決定] さぁ原点廻帰だ
[肯定] 胸に刻め
[対象] 失くしたはずの声がここにある
[呼びかけ] 酔え、酔え、鼓動まで
[維持] そのままで
[感情] 泣いて、笑って、息して
[結論] それが生きる証
```

**テンプレートB（覚悟）**
```
[決定] どうせ終わりなら
[呼びかけ] 自分で歩け
[肯定] ここにある
[対象] 死なない記憶
[呼びかけ] 笑え、笑え、傷跡ごと
[感情] それが生きる証
```

**テンプレートC（祈り）**
```
[決定] さぁ目を開けて
[呼びかけ] 聴いて、見て、感じて
[肯定] ここにある
[対象] 真実の音
[呼びかけ] 泣いて、笑って、息して
[結論] それが生きる証
```

---

## 使用方法

Phase 4 歌詞作成時に以下を適用:
1. **構造選択**: テンプレートA/B/Cから選択
2. **単語置換**: 感情単語・動詞・呼びかけを適用
3. **PC用語排除**: 前表の置換例を適用
4. **人間判断**: MiniMax評価で売れ線適合度を確認
