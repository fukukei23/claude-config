# proxy-mode — 手動モード切替（健康時の日常操作）

寝る前に「GLMに戻して」の一言で戻せます（TTL期限切れでも自動でGLMに戻ります）。

## 位置づけ（混同禁止）
- **本スキル** = 健康時の日常切替（再起動なし・TTL式・`~/bin/proxy-mode.sh` 実行）
- **proxy-doctor** = プロキシ故障時の診断・修復
- **switch-backend.sh** = プロキシ死亡時の自救（settings.json書換+CLI再起動要）→ **別物**

## フロー

### 切替（on）
1. 発話を解釈（下表）。**LLMはhours計算をしない**（計算はスクリプト内dateで完結）
2. **確認ゲートは省略**（2026-08-21運用開始時点）— 「文脈から解釈→即実行→結果表示」方式
3. `bash ~/bin/proxy-mode.sh on [hours]` を実行し、**スクリプト生出力をそのまま貼る**（再生成しない）
4. 結果表示時に「解釈内容」（復帰時刻・使用率・時間帯ガード適用有無）を先頭で明示し、ユーザーが**都合悪ければ `off` または `on <異なるhours>` で即修正**できる
6. 明示時間指定あり（「12時間で」「朝まで」等）はスクリプト側でも解釈可能・LLMの解釈は不要

### 戻し（off）
- 確認なしで `bash ~/bin/proxy-mode.sh off` を実行し、生出力を貼る

### 状態確認（status）
- `bash ~/bin/proxy-mode.sh status` を実行し、生出力を貼る

## 時間解釈ルール
| 発言 | 解釈 |
|---|---|
| 「今夜はミニマックス」（18:00-05:59発火） | 翌朝06:00まで（スクリプト自動計算） |
| 「今夜はミニマックス」（06:00-17:59発火・日中） | 8h固定（時間帯ガード） |
| 「朝まで」「明朝まで」 | on 引数なしで実行（夜間なら翌朝6時・日中は8h） |
| 「○時間」「あと○時間」 | `on <N>` |
| 「○時まで」 | その時刻までの残り時間を計算して `on <N>`（この場合のみLLMが算出してよい・端数は切り上げ） |

## バッジ（厳守）
`proxy-mode.sh status` で manual_provider=minimax かつ期限未過ぎの間は、
**返答テキストの先頭に「🟠[MiniMax]」プレフィックスを付ける**（GLMの🟡と誤認させない）。

## エラー時
スクリプトが `❌ 切替失敗（HTTP xxx）` を出した時:
(a) proxy-doctor スキルでの修復を提案 → (b) switch-backend.sh zai（最終手段・CLI再起動要）
