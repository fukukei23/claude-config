## 進行（7フェーズ・ハイブリッド）

**🔴 = 人間判断ポイント。必ず停止してユーザー確認を待つ。** 楽曲・映像制作は「聴かない/見ないと分からない」ので生成ごとに停止。

### Phase 0: 作品選択（起点）

`AskUserQuestion` で選択式:
```
質問:「どの作品スタイルで作りますか?」
選択肢（作品カタログから）:
  原点廻帰（ラウドロック×和楽器・ダーク和モダンファンタジー）
  電子参拝（Lo-Fi Hip Hop・サイバー和モダン）
  百鬼夜行（サイバー和モダンEDM・ハイパーポップ）
  ＋「その他（カスタム）」
```
選択後、`references/作品カタログ.md` からその作品の **セクション構造 / BPM範囲 / 映像世界観 / 推奨ジャンル** を提示。

### Phase 1: 設計パラメータ固め（核心5項目）

`AskUserQuestion` で順に選択式:

1. **対象情景/シーン** — 選んだ作品の映像世界観から候補提示（原点廻帰→「般若と男 / 赤い月と水面 / 夜市の宴」、電子参拝→「AI仏 / デジタル参拝 / チル瞑想」等）
2. **ジャンル微調整** — 作品の推奨ジャンル ＋ `ジャンルカタログ.md` 代表8個 ＋「その他」:
   `ラウドロック×和楽器 / Lo-Fi Hip Hop(サイバー和) / サイバー和モダンEDM / 和風トラップ / 和風アンビエント / サイバー和ヌメタル / 都節エレクトロ / 和楽器インスト`
3. **テンポ感 → BPM** — `スロー70-85 / ミドル86-100 / アップ101-115 / ファスト116+ / 数値直接指定`（作品のBPM範囲を目安に）
4. **曲の規模** — `フック8小節 / フック16小節 / 60秒 / フル3分 / フル4分`
   ※ 秒数は BPM から自動算出して表示（`秒数 = 小節数 × 4 × 60 / BPM`）。`曲構成_BPM計算.md` と `楽曲構造.md` 参照。
5. **ボーカル性別** — `男 / 女 / デュオ(F)(M) / インスト（ボーカルなし）`

### Phase 2: 歌詞制作（スキル内10ステップ・硬制約適用）

`発音ルール.md` と `固有名詞マップ.md` を厳守しながら:

1. **テーマ/情景確定** → `楽曲構造.md`（構造+サウンドロジック）+ `映像タイムライン_プロンプト.md`（世界観+情景）参照
2. 構成設計 → `曲構成_BPM計算.md` で小節数逆算
3. **漢字で歌詞執筆**（意味明確に・世界観の情景描写）
4. **ひらがな化** → `scripts/kanji_to_hiragana.py` でjanome確認（固有名詞マップ適用）
5. **発音制御** → 助詞「は→わ」**全適用**（発音ルール.md）
6. **日本語チェック** → 造語・不自然表現スキャン（1行ずつ音読）
7. **漢字版併記**（ユーザー照合用・必須）
8. **韻設計** → `韻技術.md` で母音列調整
9. **生成前チェックリスト**（発音ルール.md §6項目全確認）
10. 🔴 **人間判断**: 漢字版歌詞を提示 → **「この歌詞で生成していいですか?」**

### Phase 3: 楽曲生成

1. MiniMax MCP `music_generation`（model=music-2.6）で生成
   - prompt: ジャンルカタログの英語プロンプト指針
   - lyrics: Phase 2 のひらがな歌詞（構造タグ `[Verse 1][Chorus]` 等）
2. 🔴 **人間判断**: 聴取 → **「発音/曲調はどうですか?」**
3. **発音問題あれば music-cover ループ**（`music-cover手法.md`）:
   - 良い回を即 `music_cover_preprocess`（無料・直接API）→ `cover_feature_id`（24h有効）
   - 修正歌詞で `music-cover` 生成（直接API・MCP不可）
   - → 再聴取

### Phase 4: アートワーク（画像）

1. MiniMax MCP `text_to_image`（image-01）で構図生成
   - `映像タイムライン_プロンプト.md` の該当シーンのプロンプト（§1.3/§2.3）をベースに、Phase 1 の情景で微調整
   - 出力 `--ar 16:9`（動画ソース帧として使用）
2. 🔴 花鈿（眉間の赤点）あれば → `remove-huadian` スキルを自動呼出
3. 🔴 **人間判断**: **「構図/花鈿除去はこれでいいですか?」**

### Phase 5: 動画生成（タイムライン強化・B型核心）

1. MiniMax MCP `generate_video`（Hailuo-2.3）で生成
   - 作品別タイムライン（`映像タイムライン_プロンプト.md` §1.1/§2.1）に沿ったシーン設計
   - **静=ループモーション**（Lofi・チル）/ **動=パンアップ・フライスルー**（ラウド・EDM）を使い分け（§3 共通モーション制御参照）
   - FL2V / S2V / I2V を `00_SYSTEM/AI生成メディア_ケイパビリティマップ.md` 参照で選択
   - 最大10秒。15秒は10s+5sを2本→ffmpeg結合
2. 🔴 **人間判断**: **「動画はこれでいいですか?」**
   - Token Plan制限時: 従量課金($0.19~/本)を案内してスキップ可

### Phase 6: 成果物整理 + SSOT記録

1. 楽曲ディレクトリに格納（`/home/yn4416/Music/ai-music/サイバー和モダン/<作品名>_<情景>/`）
   - `lyrics.md`（ひらがな＋漢字版＋修正履歴）
   - `README.md`（アートワーク・動画・履歴表）
   - `_INDEX.md` 更新
2. SSOT記録（既存ルール準拠）:
   - `01_DECISIONS/ai-music/YYYY-MM-DD_<作品名><情景>.md`（詳細）
   - `10_DAILY/YYYY-MM-DD.md`（サマリー+リンク）

## エラー処理・フォールバック

| 障害 | 対処 |
|---|---|
| 🔴発音問題（聴取後） | music-coverループ（`music-cover手法.md`） |
| 🔴生成揺らぎ | 良い回を即 preprocess 保存（cover_feature_id は24h有効） |
| 🔴動画Token Plan制限 | 従量課金($0.19~/本)案内してスキップ可 |
| 🔴花鈿（眉間の赤点） | `remove-huadian` スキルを自動呼出 |
| 🔴造語/漢字誤読 | Phase 2 の品質チェックで硬制約（janome+固有名詞マップ・人間最終確認） |

## 重要: MCP説明文 ≠ 公式仕様

`music_generation` MCP説明文に「up to 1 minute」とあるが**誤り**。曲長は BPM×小節数で決まり、5分曲も可能。長さ・コスト・機能の上限は `references/曲構成_BPM計算.md` と `00_SYSTEM/AI生成メディア_ケイパビリティマップ.md` を信じる。
