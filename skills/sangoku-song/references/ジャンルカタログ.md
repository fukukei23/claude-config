## 音楽プロンプト記述の指針

各ジャンルをMiniMax music-2.6のprompt欄に記述する際、**構造化フォーマット**（ジャンル＋楽器＋スケール＋ボーカル＋世界観＋構造）で書くと精度が上がる。詳細な音作りは `サウンドデザイン.md` 参照。

### 構造化プロンプトフォーマット（曹仁v8実績ベース）
```
[ジャンル] / [サウンド特性] / [BPM] / [ボーカル] / [世界観] / [スケール] / [構造]
```
